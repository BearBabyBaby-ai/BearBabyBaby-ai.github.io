# 熊寶編年史 v22 戰況重製版

## 開始遊玩

先將整個 ZIP 下載並解壓縮，檔案之間的目錄關係必須保留。Windows 可雙擊 `Launch_App_Windows.bat`，以 Edge／Chrome 的獨立視窗啟動；找不到時會使用預設瀏覽器開啟。也可直接開啟 `index.html`。這兩種方式可離線遊玩，不需要額外套件。

## 安裝為 PWA

使用已安裝 Python 3 的電腦，執行 `Start_PWA_Windows.bat`，或在這個資料夾執行 `python3 serve.py`，以本機網址啟動。請保持服務視窗開啟。Chrome／Edge 在符合安裝條件時，會顯示「安裝 App」或提供瀏覽器選單的安裝入口。iPhone／iPad 可在 Safari 選單加入主畫面；需要先放在 HTTPS 網站上。首次載入並完成快取後，可透過已安裝 App 離線遊玩。

`manifest.webmanifest`、`sw.js` 與圖示均已備妥。本機檔案直接開啟時，遊戲仍可玩，但不會註冊 Service Worker。雲端硬碟是下載存放位置，請勿在其預覽視窗執行遊戲。

## 系統內容

- 八個功能入口：即時戰鬥、冒險場景、裝備配裝、鍛造、夥伴、商會、技能、手冊。
- 90 種主祀夥伴（其他夥伴已刪除）、604 間餐食商店、181 個景點場景。
- 鍛造／批次鍛造／重鑄、裝備等級／強化／升階、分解／販售與鎖定保護。
- 均衡／物理／法術／坦克評分、自動比對、一鍵最佳配裝及掉落後自動最佳化。
- 144 種主動技能上限 50 級、24 種被動上限 30 級、自動技能上限 6 格。
- 冒險完成條件、首領挑戰、單次領獎與景點集章。
- 餐食庫存、恢復、限時增益、商會委託與聲望。
- 本機保存、JSON 匯出／匯入與 v19／v20／v21 遷移。
- Claude 接手視窗與版本化程式介面。

## 進度與備份

單機 HTML、本機 App、PWA 或不同瀏覽器的保存空間可能不同。請先在舊版「設定」匯出 JSON，再到新版匯入。保留原檔與備份。PWA 快取只保存程式，不會上傳玩家進度。所有遊戲價格、能力與獎勵都是虛構設定。

## 給 Claude

閱讀 `CLAUDE.md` 與 `HANDOFF.md`。開啟遊戲上方的「Claude 接手」，填寫接下來的需求，複製說明並匯出進度 JSON。將這份接手包與 JSON 交給 Claude 即可繼續。

## v22 介面與成長

- 戰鬥頁已重新設計為場景指揮、熊寶生命／魔力、即時敵情、角色屬性、自動技能與獨立紀錄。
- 手機固定底部八個功能入口，戰鬥另有戰況／角色／技能／紀錄四個分區，內容各自捲動。
- 每個功能有獨立主題色、清楚字色與較大控制區，場景以固定色相區分，名稱不重複顯示。
- 90 位夥伴各有獨立 12 節點天賦樹，三條分支；只在出戰時生效。
- 商會委託增為 48 種，五大類別、各自可循環多輪。
- 角色與裝備統一 PATK／MATK／MP，匯入時相容 MPATK 等舊別名。
- 舊版非主祀夥伴會移除，招募與培養投入的金幣／粉塵會一次返還。
